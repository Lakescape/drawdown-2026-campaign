## 2. Master Enhancement Prompts (Feed These to Other LLMs)

### Prompt A — Overall System Critique & Strengthening
```
You are a ruthless chief of staff and high-ticket sales operator who has scaled multiple $1M+ seasonal campaigns.

Here is the full Drawdown 2026 system we have built so far: [paste this entire Enhancement Prompt Pack + all linked documents].

Your job:
1. Identify the three weakest links that are most likely to prevent us from hitting $1M.
2. Strengthen the sales sequence and rebuttals so they feel less “scripted” and more like a trusted advisor talking to a high-net-worth Lake Austin homeowner.
3. Propose a tighter daily operating rhythm for a 4-person sales team that still protects the relationship equity of the warm list.
4. Suggest any missing measurement or early-warning metrics we should add to the Quality Gate Scorecard.
5. Rewrite any section that feels generic or soft.
```

### Prompt B — Media & Ad Creative Volume
```
You are a direct-response creative director who specializes in high-ticket residential and scarcity-driven campaigns.

Context: Lake Austin drawdown, first in ~10 years, Priority Assessment $695 fully credited, limited amphibious machine-days.

Generate:
1. 12 different Meta/Instagram ad angles (problem-aware, solution-aware, most-aware)
2. 8 short video scripts (8–15 seconds) for Reels/TikTok that create FOMO without looking salesy
3. 6 static image ad concepts with exact headline + primary text + CTA
4. 4 email subject lines + preview text pairs for the past-client blast
5. 3 door-hanger / yard-sign headlines that work on high-end Lake Austin properties

Make everything feel premium, local, and slightly urgent. Avoid corporate or hype language.
```

### Prompt C — Sales Script Hardening
```
Take the current warm-list call script, SMS sequence, and rebuttal library.

Rewrite them so they:
- Sound like a calm, highly competent local expert who already has the machines locked
- Increase the perceived cost of inaction without pressure
- Make the $695 Assessment feel like the obvious, low-risk next step
- Handle the spouse/partner objection more elegantly
- Create a natural multi-thread into the household when appropriate

Output the full revised scripts and a new “objection → micro-commitment” table.
```

### Prompt D — Automation & Agent Improvement
```
We have a planned flow: Quo transcript → AI synthesis → database update → Kanban card.

Here is the current synthesis prompt and Kanban stages: [paste].

Improve it by:
1. Making the interest_score more predictive of deposit likelihood
2. Adding a “machine-day risk” flag if the work requires amphibious access
3. Suggesting a daily digest format that a 4-person sales team will actually read
4. Proposing the exact n8n or Mastra node structure (or Hermes agent instructions) that would make this reliable
```

### Prompt E — Resource & Capacity Stress Test
```
Here is our Resource Plan and Capacity Model for the $1M Target case.

Run three stress scenarios:
1. Only 1 amphibious machine is secured
2. Warm-list conversion is 30% lower than planned
3. Utilization lands at 65% because of weather + permit delays

For each scenario, tell us exactly what we should cut, what we should still protect, and what the revised revenue floor becomes. Then recommend the decision gates we should put in Linear.
```

### Prompt F — Full Document Polish Pass
```
Here are all the current Markdown documents for the Drawdown campaign.

Do a single consistency and voice pass:
- Make language uniform (calm authority, local expertise, real scarcity)
- Remove any remaining hedging or soft language
- Ensure every document points to the same numbers (utilization, crew count, Assessment price, etc.)
- Flag any contradictions between the Grand Slam, Resource Plan, and Sales Playbook
```
