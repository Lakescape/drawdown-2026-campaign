# Earth Pro Runbook — 2017 Lake Austin Drawdown Frames

**Goal:** capture the *true drawdown-condition* imagery (lake at −10 ft) for all 39 target areas + 9 cove/channel features, matching the current-condition shots in this pack for before/after pairs.
**Time required:** ~30–40 minutes. **Cost:** free.

---

## 0. Why this is a local step
Google Earth's historical-imagery time slider exists **only in Google Earth Pro (desktop)** — not in Google Earth Web or the mobile app. The 2017 drawdown imagery lives in that layer.

## 1. Setup (2 min)
1. Install/open **Google Earth Pro** (desktop) — free: https://www.google.com/earth/about/versions/#earth-pro
2. **File ▸ Open…** → select `lake-austin-shotlist.kml` from this pack. You'll get tiered folders (A / B / C / Coves & Channels) in *Temporary Places* — drag them to *My Places* to keep them.
3. Set clean screenshots: **Tools ▸ Options ▸ Navigation** → uncheck "Show navigation controls". **View** menu → turn OFF: Sidebar, Status bar, Atmosphere, Water Surface (optional — off makes drawdown exposure crisper), and all Layers you don't need (keep *Borders and Labels* off for clean sales shots, or on if you want road names).

## 2. Set the 2017 drawdown window (1 min)
1. Click the **clock icon** (Historical Imagery) in the toolbar — a time slider appears top-left.
2. Drag the handle into **Jan 15 – Feb 28, 2017**. The drawdown ran Jan 2 – Feb 13, 2017; the lake sat at its **fully lowered floor (~−10 ft) roughly the last two weeks of that window** — target **Feb 1–13, 2017** imagery where available.
3. **Check the capture date** shown with the slider/status for each location — imagery dates vary block-by-block across the lake. Rules:
   - Prefer a frame dated **within the drawdown window** (Jan 2–Feb 13, 2017).
   - If none exists for a spot, take the **closest 2017 frame before refill completed** (refill done ~late Feb 2017) and note the date.
   - Record the date you used per shot in the checklist below.

## 3. Shooting procedure per placemark (~45 sec each)
1. Double-click the placemark — Earth flies to the pre-set camera (context framing). For A-tier areas, also zoom one step tighter for the detail shot.
2. Verify the historical date stamp is still in-window (flying can change the tile set).
3. **File ▸ Save ▸ Save Image** → set resolution **1920×1080** (or 4K on the Pro max), turn OFF title/legend/compass overlays in the Save Image toolbar, click **Save Image**.
4. **Name it to match this pack** so before/after pairs line up automatically:
   `{slug}__2017_context.png` and `{slug}__2017_detail.png` (slugs are the filenames in `screenshots/tier-*/`).
   Save into `screenshots-2017/tier-A|B|C/` folders you create next to the existing ones.

## 4. Shot order (priority)
1. **Tier A (19 areas)** — do all of these; both context + detail. N5 The Island canal grid is the crown jewel: the canal system fully exposed is the single best sales image on the lake.
2. **Coves & channels folder (9)** — Bull Creek delta, Bee Creek arm, Panther Hollow, Oyster Landing basin.
3. **Tier B (11)** — context + detail.
4. **Tier C (9)** — context only, quick passes (they're benchmarks/context, low direct revenue).

## 7. Notes & gotchas
- **Imagery availability varies.** Some shoreline blocks have excellent Feb-2017 frames; a few may only have Jan-2017 (partially lowered — still visibly down ~6–8 ft) or spring-2017 (refilled). Record what you got.
- **Do NOT use "3D buildings" tilt for these** — straight-down (tilt 0°) matches the current-condition pack for clean before/afters. If you want a couple of dramatic obliques for the sales deck (Pennybacker Bridge, The Island), take those as *extras*, clearly labeled.
- While you're in there: the **2026 drawdown is under active City/LCRA discussion** (Oct/Nov 2025 city memos). If it happens, this same KML is your re-shoot list — which makes this pack a reusable asset, not a one-off.
- Alternative if a machine with Earth Pro isn't handy: **Sentinel-2 via EO Browser** (free) has real Feb-2017 captures of the whole lake at 10 m/pixel — good for cove-scale exposure, useless for individual docks.
