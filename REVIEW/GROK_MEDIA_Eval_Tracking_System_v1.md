# GROK_MEDIA_Eval_Tracking_System_v1
**Drawdown 2026 Creative Scoreboard & Feedback Loop**

---

## Purpose
Close the loop between production → distribution → performance → improvement.  
No more “we posted it and hoped.”

---

## Weekly Creative Scoreboard (Every Monday)

| Asset ID | Platform | Posted | Impressions | Primary Metric Result | Booked Assessments | Decision | Notes / Lesson |
|----------|----------|--------|-------------|-----------------------|--------------------|----------|----------------|
| DD26-HERO-IG-REEL-001 | IG Reels | | | Saves / Watch-through | | Kill / Iterate / Scale | |
| DD26-HERO-TT-001 | TikTok | | | Rewatches / Comments | | | |
| ... | | | | | | | |

**Decision Rules:**
- **Scale:** Clear booked Assessments or strong leading indicators + positive qualitative signals
- **Iterate:** Decent attention but weak conversion → new hook / new CTA / new creative angle
- **Kill:** No business result after meaningful delivery + poor leading indicators

Primary optimization target remains **Cost per Booked Assessment** (or pure booked volume on organic).

---

## Required Logging Fields (per post)

- Asset ID
- Platform + format
- Post datetime (CT)
- Creative version / hook used
- Audience (Past client / Warm / Cold / Lookalike)
- Spend (if paid)
- Leading metrics (platform-native)
- Lagging metric: Booked Assessments (7-day and 14-day)
- Qualitative notes (comments themes, DM quality)
- Lesson learned (one sentence)

---

## Feedback into Production

1. Winning hooks get documented in a “Hook Library”
2. Losing angles get retired or rewritten
3. Platform-specific learnings update the Platform Attention Economics skill
4. Every major lesson is filed so the next campaign starts smarter

---

## Tools Recommendation

- Linear = source of truth for tasks and status
- Simple Google Sheet or InsightEngine dashboard for the weekly scoreboard
- UTM parameters on every link (source / medium / campaign / content = Asset ID)
- Manual logging acceptable at current volume; automate later
