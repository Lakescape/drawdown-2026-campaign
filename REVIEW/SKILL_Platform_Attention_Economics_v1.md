## Production Sequence (Skill Steps)

When the user says “produce for every platform” or “platform-tune this”:

1. **Source Asset** — Start from the approved master (Hero Reel, Script, Static, Offer card)
2. **Platform Matrix** — Map the single Big Idea across the table above
3. **Native Rewrite** — Rewrite hook, length, text overlay density, CTA, and caption for each platform’s contract
4. **Visual Adjust** — Crop, speed, text size, safe zones for each format (9:16, 1:1, 4:5, 16:9)
5. **Gate Check** — Run Pillar 7 + Hallucinations + Gate 0 language on every version
6. **Package** — Output ready-to-post files + captions + hashtags + posting window
7. **Tracking Tag** — Assign UTM + internal ID so performance can be logged
8. **Eval Hook** — Define the leading indicator for that platform (saves, rewatches, replies, booked Assessments)

## Jab-Jab-Jab-Right-Hook Cadence (Adapted for High-Ticket)

- **Jab:** Soft scarcity or “we’re preparing” update
