## Campaign rules enforced across every file (check us on these)

1. **Hedged drawdown language only** — "exploring" / "lined up" / "projected". No file may assert the drawdown "is happening".
2. **Real numbers only** — approved structural scarcity: 2 amphibious machines locked, ~25 working days, "we committed in July". Live counts exist only as [X] placeholders fed by Mon/Thu standup. The old "47 machine-days / 31 spoken for" figures are banned.
3. **No competitor-incapacity claims** — we state what we locked, never what others can't get.
4. **Rep identity discipline** — reps speak as themselves; Nathan's name is never scripted into a rep's mouth (caught + fixed in voicemails).
5. **GSM-7 SMS** — every customer-facing text is single-segment, ≤160 chars worst-case, zero em dashes/smart quotes.
6. **Referral embargo** — the $500 credit launches Oct 15; pre-launch scripts use the "first in line" gate.
7. **$695 / 100% credited / 12-month validity** — consistent in all 11 files. Window-shift terms verbatim: "refund, roll, or credit."
