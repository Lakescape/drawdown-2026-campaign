## Rotation

Folder name = **Monday** of the work week (`YYYY-MM-DD`).

Sunday night / Monday morning:

1. `mkdir weeks/YYYY-MM-DD`
2. Copy last week’s open rows into the new `BOARD.md` (don’t delete the old folder)
3. Rewrite `weeks/CURRENT` to the new Monday
4. Leave renders in `06_Media_Build/` — they are the library, not the dump

Do not put Ready cards on Hermes `studio-post` for this. Claude reads **files**. Hermes writes **files**.
