# ATX LakeScapes — full-length lyrics, v2

Written 2026-09-04. Supersedes the four-line chorus in `PROMPTS.md` track 3, which
was a hook stub, not a song. These are full verse/chorus/bridge structures for
~3-minute tracks.

## Rules these were written under

**Claim discipline, same as every other surface on this campaign:**

- The drawdown is **official** — LCRA announced 2026-08-29. Lyrics may state it as fact.
- **Depth stays hedged.** "Ten to twelve, and they're calling it projected." Never a
  flat number.
- **No dates.** The Oct–Nov window is a pointer, not a schedule. Nothing sings a date.
- **Banned everywhere:** exploring, unofficial, "nothing is official yet", $695,
  credited, assessment, extinct.
- **No business claims.** No booked-calendar, no volume, no guarantee, no price. A song
  cannot be held to a number, so it does not name one.
- **Phone number IS sung in B's tag — Nate's call, 2026-09-04.** Written first without
  it, on the reasoning that a sung number is the carnival-jingle failure the style
  brief bans. Nate overruled that and it is in. Digits are spelled out
  ("Two five four…") for the same reason `CAPTIONS_2026-08-30` spells "six ninety-five"
  — models read raw digit strings inconsistently.
  ⚠️ Correction to an earlier note in this repo: `PROMPTS.md` never had the number in
  its tag. Its track 3 tag is `ATX LakeScapes` alone. This is an addition, not a
  restoration.
- Not a jingle. Not a barker. BBQ test — this should sound like somebody who does the
  work, not somebody selling it.
